# RaceDayFinal - Part 2 API + Part 3 MVC

## Run
1. Open RaceDayFinal.sln in Visual Studio 2022
2. Set Startup Projects to Multiple: RaceDay.API + RaceDay.MVC
3. Press Play. API: https://localhost:7018/swagger

## Features
- Organiser: Dashboard, Create Event with banner image, View Enrolments, Save Result
- Participant: Browse Events, Enrol, My Events, My Results, Profile with picture upload
- Auth: JWT, Role-based Organiser / Participant
- Azure Blob: Banner + Profile pictures uploaded to raceday-images container
- Docker: RaceDay.MVC Dockerfile, runs on port 8080
